为什么需要账号？

检查不需要登录。登录后可以提交真实错读案例、给案例投票，并保留自己的投稿记录，方便词库维护者审核。

原文会被保存吗？

不会。检查接口只在内存里处理文本，不把原文写入数据库；数据库保存的是词条、案例和账号信息。

还想要零依赖版本？

静态版仍然保留在 /lite/，可单独部署到 Cloudflare Pages、Netlify 或 GitHub Pages，不需要数据库。

About v2

为什么从静态站升级到前后端

静态版解决“打开就能用”，v2 解决“词库和案例可以持续沉淀”。两者不是替代关系。

v2 架构

  • Go 标准库 HTTP 服务，单二进制部署
  • PostgreSQL 存储词条、读音、账号、案例和投票
  • 原生 HTML/CSS/JS 前端，无 Node 构建步骤
  • 服务端检查接口，词库更新后全站立即生效
  • 静态轻量版保留在 /lite/

安全边界

  • 密码使用 bcrypt 哈希，会话 Cookie 为 HttpOnly + SameSite=Lax
  • 所有 SQL 使用参数化查询，写操作做同源检查
  • 登录、注册、检查和投稿都有独立的速率限制
  • 检查原文不落库，数据库只保存词条和案例
  • 生产环境请开启 HTTPS，并设置 COOKIE_SECURE=true
