为什么不是“一键修音”？

多音字错误发生在文本到读音的映射，不是音质问题。先在写稿阶段排雷，成本最低；成片修复需要重新合成、对齐和替换音轨，适合作为下一步。

怎么用最省事？

把文案粘进来，确认高风险词，复制“标注稿”或 SSML，再交给剪映、讯飞、腾讯云/百度 TTS。标注稿里的拼音可以直接人工核对。

词库怎么共建？

发现漏词或误报，点结果卡片里的“导出案例”，把 JSON 贴到 GitHub Issue。词库是公开的，贡献者会被记录。
